# llmname

Proyek eksperimen identifikasi model pembuat teks dengan EDA dan pipeline modular.
Baseline awal: LinearSVC dengan TF-IDF word/character dan fitur gaya.

Gunakan Python 3.12 atau lebih baru. Seluruh alur tersedia melalui `make help`.
Instalasi: `make setup`. Data kompetisi tetap berada di `name-that-llm/` dan tidak
disertakan dalam Git. Dependensi Kaggle bersifat opsional.

Panduan lokal berada di `docs/`; dokumentasi privat tersebut tidak di-commit.
Training penuh, tuning, commit, dan push memerlukan persetujuan tersendiri.
